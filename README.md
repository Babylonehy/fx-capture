# 中国银行汇率截图

一个跨平台 Electron 桌面应用，用于：

- 导入日期列表
- 打开中国银行外汇牌价查询页
- 逐个日期查询指定币种
- 将结果页截图保存到指定目录

当前版本采用 **人工输入验证码 + 自动批量执行** 的方式。这是因为目标站点存在验证码校验，纯自动化方案稳定性较差。

## 功能说明

- 支持导入 `.txt` / `.csv` 日期文件
- 支持直接在界面中粘贴日期列表
- 支持通过日期选择器手动逐条添加日期
- 支持选择币种
- 支持选择截图输出目录
- 每个日期保存一张 PNG 截图，默认文件名为 `YYYY-MM-DD.png`
- 运行时会弹出验证码输入层，输入后自动继续下一个日期
- 验证码输入层会显示当前任务进度
- 任务完成后可一键打开输出目录

## 日期格式

每行一个日期，例如：

```txt
2026-03-20
2026-03-21
2026-03-22
```

示例文件见 [examples/dates.txt](./examples/dates.txt)。

## 开发运行

先安装依赖：

```bash
npm install
```

启动应用：

```bash
npm start
```

## 打包

生成安装包：

```bash
npm run dist
```

说明：

- macOS 下可生成 `dmg`
- Windows 下可生成 `nsis`
- Linux 下可生成 `AppImage` / `deb`

通常建议在对应操作系统上执行打包，以避免签名和目标格式兼容问题。

## 运行流程

1. 导入日期文件或直接粘贴日期列表
2. 选择币种
3. 选择截图输出目录
4. 点击“开始批量截图”
5. 每处理一个日期时，应用会显示当前验证码
6. 输入验证码后，程序自动查询并保存截图

## 项目结构

```txt
src/
  main.js              Electron 主进程，负责自动化和截图
  preload.js           安全 IPC 桥接
  renderer/
    index.html         桌面界面
    renderer.js        前端交互逻辑
    styles.css         样式
examples/
  dates.txt            日期列表示例
```

## 已知限制

- 目标网站存在验证码，因此当前版本无法做到完全无人值守。
- 页面结构如果后续调整，可能需要同步更新表单识别逻辑。
- 如果同一日期没有查询结果，任务会记录失败并继续处理下一个日期。
